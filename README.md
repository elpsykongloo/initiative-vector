# Reference-Guided Turn-Taking Style Transfer — audio examples

Project page for *Reference-Guided Turn-Taking Style Transfer for Full-Duplex Spoken Language Models* ([arXiv:2610.20763](https://arxiv.org/abs/2610.20763)).

The page is a static site served by GitHub Pages from this repository's root: `index.html`, `assets/`, `audio/` and `data/samples.js`.

## Data and models

Conversations and reference recordings are excerpts from [Seamless Interaction](https://github.com/facebookresearch/seamless_interaction) (Meta), licensed [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/). The audio in `audio/` is shared under the same license, for non-commercial research use.

Model outputs were generated with [Moshika](https://huggingface.co/kyutai/moshika-pytorch-bf16), [Moshika-RL](https://huggingface.co/kyutai/moshika-rl-seamless) and [PersonaPlex-7B-v1](https://huggingface.co/nvidia/personaplex-7b-v1); see each model card for its license.
