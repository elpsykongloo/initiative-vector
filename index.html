Reference-Guided Turn-Taking Style Transfer for Full-Duplex Spoken Language Models

Every set of full-duplex weights speaks with one turn-taking personality. We turn it into a knob you can set per person.

Same model, same conversation, no training and no retraining. A five-minute recording of a speaker is enough to move the model's turn-taking toward that speaker.

01 · Sounds like you

One target conversation, two references, opposite directions

Each reference is a five-minute recording of another speaker in their own conversation; it only sets the dose. The model then talks in one target conversation, the same as in the no-steering clip, with the same partner (left channel). A quiet reference pulls the model below its default, a talkative one pushes it above. Doses are steps along the initiative vector (see 02).

02 · Hear it change

Five doses, one conversation, one seed

Same input, same random seed; only the dose added along the initiative vector changes, from −2a to +2a. The model goes from barely speaking to holding the floor. The same direction and scale carry over to a second corpus, CANDOR, without refitting.

03 · It is this direction

Same displacement, random direction: the model does not take the floor

Same conversation as the dose sweep. All four clips share input, seed and displacement (+2a); only the direction differs. Swap the initiative vector for random unit directions, injected at the same layer with the same norm: the model does not start taking the floor. Only the initiative vector pushes it up.

04 · It knows before it speaks

The projection rises before the model takes the floor

Unsteered model on a representative held-out conversation. The curve is the per-frame projection of the L30 residual on the initiative vector, shown while the model is silent (the frames the readout is scored on); colored spans are where the model speaks. The projection climbs while the model is still silent and peaks as it takes the floor, anticipating onsets up to 800 ms ahead. The same direction that shifts the decision also reads it before any audio comes out.

Data and models

Conversations and reference recordings come from Seamless Interaction (Meta), released under CC BY-NC 4.0. Excerpts are trimmed, resampled to 24 kHz and loudness-matched; the audio on this page is shared under the same license, for non-commercial research use.

Models: Moshika (Kyutai), Moshika-RL (Kyutai, post-trained with RL on Seamless Interaction), and PersonaPlex-7B-v1 (NVIDIA). See each model card for its license. Model outputs on this page were generated by the authors with these weights, unmodified except for the steering described above.
